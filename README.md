# 365 дней · веб-трекер

Это рабочая локальная MVP-версия без регистрации и без сервера.

## Запуск

1. Распакуйте архив.
2. Откройте `index.html` в браузере.
3. Выберите профиль «Бека» или «Подруга».
4. В настройках задайте дату старта.
5. Отмечайте привычки, добавляйте вес, замеры и заметки.

## Что уже работает

- два профиля: Бека и Айжана;
- дата старта и автоматический номер дня;
- обычный календарь;
- пропущенные дни;
- 11 ежедневных привычек;
- йога через день, автоматически;
- процент дня;
- текущая и лучшая серия;
- календарные статусы;
- прогресс каждой привычки;
- вес и замеры;
- фонд красоты;
- награды с повторением: каждые −5 кг, −10 кг и каждые 30 дней полной серии;
- цели;
- заметки;
- общий экран «Мы вдвоём» с полным взаимным доступом к весу, замерам, питанию, заметкам, привычкам, сериям и наградам;
- адаптация под телефон и компьютер;
- сохранение через localStorage.

## Важно

Сейчас данные хранятся локально в браузере. Поэтому два разных телефона пока не синхронизируются.

Следующий этап для общей ссылки: подключить Supabase (авторизация по простому коду/PIN, таблицы пользователей, дней, привычек, веса, замеров, целей и наград), затем опубликовать сайт на Cloudflare Pages или GitHub Pages.
